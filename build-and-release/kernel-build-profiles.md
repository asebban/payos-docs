# payos-kernel build profiles (obsolete — see v1)

**Last updated:** 2026-10-31

The two-source-directory/Maven-profile mechanism this page described (`src/main/java-dev`/`src/main/java-prod`, `-Pprod`) has been removed entirely — it no longer exists in `payos/pom.xml` or `payos-runtime/pom.xml`. Dev vs. production validator selection is now a runtime toggle, not a build-time one.

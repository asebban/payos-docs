# Internationalization configuration

The `i18n` block controls how PayOS resolves the request locale and selects translation
messages. Developer usage (translation files, `$I18n`) is in
[developer/internationalization.md](../developer/internationalization.md).

## Shape

```json
{
  "i18n": {
    "headerName": "Accept-Language",
    "defaultLocale": "en",
    "fallbackLocale": "en",
    "supportedLocales": ["en", "fr", "ar"]
  }
}
```

## Keys

From `IConfigSpec.I18n`:

| Key | Purpose |
| --- | --- |
| `headerName` | Request header carrying the requested locale. |
| `defaultLocale` | Locale used when none is provided in the request. |
| `fallbackLocale` | Locale used when a key is missing in the requested locale. |
| `supportedLocales` | Allowlist of locales the runtime will honor. |

## Resolution flow

```
request header (headerName)
  → if present and in supportedLocales → use it
  → else → defaultLocale
key lookup miss → fallbackLocale
```

## Translation files

Messages live per application in `i18n/<locale>.json`. See
[developer/internationalization.md](../developer/internationalization.md).
